## Why

Фича генерации упражнений уже прошита сквозным потоком (бот → use case → Spring AI → проверка ответа), но пока не соответствует правилам из `src/main/resources/exercise/examples.MD` и roadmap. Упражнения генерируются из *всех* слов словаря, промпты путают содержательную тему с грамматическим правилом, а промпт multiple-choice проверяет знание слова, а не грамматику. Из-за этого преподаватель не может надёжно сгенерировать грамматическое упражнение по активной лексике ученика.

## What Changes

- **Фильтр слов по статусу изучения**: генерировать упражнения только по словам со статусом `IN_PROGRESS` (roadmap: «слова в статусе на изучении»), а не по всему словарю.
- **Грамматическое правило как входной параметр первого класса**: поток генерации принимает грамматическое правило (например, «Past Simple»), которое проверяет упражнение, в дополнение к существующей содержательной теме. Бот собирает его новым шагом.
- **Соответствующие правилам промпты**: переписать оба AI-промпта согласно `examples.MD`:
  - FILL_IN_THE_BLANK: один `___` на предложение, пропуск проверяет грамматическое правило, ровно один однозначный ответ, целевая лексика используется как контекст.
  - MULTIPLE_CHOICE: один `___` на предложение, ровно 4 варианта, ровно один правильный, дистракторы — типичные грамматические ошибки, правильные ответы распределены по позициям.
- **Настраиваемое число предложений**: заменить захардкоженные `10` / `3` на конфигурационное свойство (дефолты сохраняют поведение).
- **Структурированная модель ответов**: ожидаемые ответы упражнения хранятся по-вопросно (JSON-модель `AiExerciseResponse` со списком пунктов), а не одной строкой через запятую; проверка ответа — по каждому пункту.
- **Валидация ответа**: отклонять пустые/невалидные ответы AI и сохранять существующий fallback.

## Capabilities

### New Capabilities

- `exercise-generation`: генерация упражнений FILL_IN_THE_BLANK и MULTIPLE_CHOICE на основе грамматического правила по лексике ученика в статусе `IN_PROGRESS`.

## Impact

- **Модуль exercise**: `GenerateExerciseCommand` (добавить грамматическое правило / число предложений), порт `ExerciseGenerator`, `SpringAiExerciseGenerator` (промпты, валидация), `GenerateExerciseUseCase` (фильтр слов), `AiExerciseResponse` + `Exercise`/`ExerciseDto` (структурированная модель ответов), `CheckExerciseUseCase` (по-вопросная проверка).
- **Модуль dictionary**: `FindWords` / `WordProjection` получают статус слова, чтобы use case упражнений мог фильтровать `IN_PROGRESS`.
- **Модуль chatbot**: новое состояние + переход + сообщение для сбора грамматического правила; существующий шаг темы уточняется как содержательная тема.
- **Конфиг**: новое свойство в `application.yaml` для числа предложений по умолчанию.
- **Без** изменений persistence и ломающих изменений API для других модулей.
