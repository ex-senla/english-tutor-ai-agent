## Purpose

Генерация грамматических упражнений по английскому языку (fill-in-the-blank и multiple choice) из лексики ученика, которая сейчас находится в изучении.

## ADDED Requirements

### Requirement: Словарь фильтруется по статусу изучения

Система MUST генерировать упражнения, используя только слова словаря со статусом `IN_PROGRESS`. Слова со статусом `NEW` или `LEARNED` MUST NOT использоваться.

#### Scenario: Словарь со смешанными статусами

- **WHEN** словарь содержит слова со статусами `NEW`, `IN_PROGRESS` и `LEARNED`
- **THEN** сгенерированное упражнение использует только слова со статусом `IN_PROGRESS`

#### Scenario: Нет подходящих слов

- **WHEN** в словаре нет слов со статусом `IN_PROGRESS`
- **THEN** система сообщает об ошибке, что нет слов в статусе изучения, и не создаёт упражнение

### Requirement: Грамматическое правило — обязательный входной параметр

Генерация MUST требовать грамматическое правило (например, `Past Simple`), которое определяет, что проверяет упражнение. Грамматическое правило MUST NOT быть пустым.

#### Scenario: Грамматическое правило задано

- **WHEN** генерация запрошена с грамматическим правилом `Past Simple`
- **THEN** каждый пропуск в сгенерированном упражнении требует применения правила Past Simple

#### Scenario: Грамматическое правило отсутствует

- **WHEN** генерация запрошена без грамматического правила или с пустым правилом
- **THEN** запрос отклоняется с ошибкой

### Requirement: Правила упражнения Fill-in-the-blank

Для упражнения FILL_IN_THE_BLANK система MUST генерировать предложения, в которых каждое предложение содержит ровно один пропуск (записанный как `___`), пропуск проверяет заданное грамматическое правило, существует ровно один однозначный правильный ответ, а целевая лексика используется для создания контекста и не определяет ответ.

#### Scenario: Один пропуск на предложение

- **WHEN** генерируется упражнение FILL_IN_THE_BLANK
- **THEN** каждое предложение содержит ровно один `___`

#### Scenario: Пропуск проверяет грамматическое правило

- **WHEN** генерируется упражнение FILL_IN_THE_BLANK с грамматическим правилом `Past Simple`
- **THEN** пропущенное слово в каждом пропуске — форма Past Simple глагола, и её нельзя определить без применения правила

### Requirement: Правила упражнения Multiple-choice

Для упражнения MULTIPLE_CHOICE система MUST генерировать предложения, в которых каждое предложение содержит ровно один пропуск (записанный как `___`) и ровно четыре варианта ответа, из которых ровно один правильный. Неправильные варианты MUST представлять собой правдоподобные грамматические ошибки, связанные с грамматическим правилом, а правильные ответы MUST быть распределены по позициям вариантов.

#### Scenario: Четыре варианта с одним правильным ответом

- **WHEN** генерируется упражнение MULTIPLE_CHOICE
- **THEN** каждый вопрос имеет ровно четыре варианта и ровно один правильный

#### Scenario: Дистракторы грамматические

- **WHEN** генерируется упражнение MULTIPLE_CHOICE с грамматическим правилом `Past Simple`
- **THEN** неправильные варианты представляют типичные ошибки образования Past Simple, а не несвязанные слова

### Requirement: Структурированная модель ответов

Ожидаемые ответы упражнения MUST храниться в структурированном виде: по одному ответу на каждый пункт (предложение для FILL_IN_THE_BLANK, вопрос для MULTIPLE_CHOICE), а не одной строкой. Проверка ответа MUST выполняться по каждому пункту отдельно.

#### Scenario: Ответы соответствуют пунктам

- **WHEN** упражнение состоит из N предложений/вопросов
- **THEN** модель ответов содержит ровно N ожидаемых ответов, по одному на пункт

#### Scenario: По-вопросная проверка

- **WHEN** ученик отправляет ответы на упражнение
- **THEN** система проверяет каждый пункт отдельно и возвращает результат по каждому пункту

### Requirement: Число предложений настраивается

Система MUST генерировать число предложений, заданное конфигурацией, а не фиксированное захардкоженное значение.

#### Scenario: Учитывается настроенное число

- **WHEN** настроенное число предложений равно 5
- **THEN** сгенерированное упражнение содержит ровно 5 предложений

### Requirement: Сбой генерации обрабатывается корректно

Если AI-сервис даёт сбой или возвращает пустой либо невалидный ответ, система MUST возвращать fallback-упражнение, помеченное как сгенерированное, чтобы поток не падал.

#### Scenario: AI-сервис недоступен

- **WHEN** AI-сервис выбрасывает ошибку или возвращает пустой контент
- **THEN** система возвращает fallback-упражнение, и вызывающий код может продолжить проверку ответа
