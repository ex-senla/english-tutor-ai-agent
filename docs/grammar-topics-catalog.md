## Принципы организации каталога в ETA

1. Каталог представляет собой дерево с произвольной глубиной вложенности.
2. Каждый узел является грамматической темой и может содержать дочерние темы.
3. Каталог является единым глобальным справочником, общим для всех преподавателей и учеников.
4. Уровни CEFR (A1–C2) не зашиваются в иерархию каталога. Одна тема может быть связана с несколькими уровнями.
5. Учебный порядок задаётся отдельно от структуры каталога: преподаватель или учебная программа могут выстраивать собственную последовательность тем.
6. В дальнейшем к теме можно привязывать теорию, примеры, упражнения, тесты и материалы.

## Рекомендуемые поля сущности GrammarTopic

| Поле | Назначение |
|------|------------|
| `id` | Уникальный идентификатор |
| `parent_id` | Идентификатор родительской темы; `null` для корневых разделов |
| `name` | Название темы на английском |
| `name_ru` | Название темы на русском |
| `description` | Краткое описание темы |
| `slug` | Стабильный уникальный код темы |
| `sort_order` | Порядок отображения среди соседних узлов |
| `is_active` | Признак доступности темы |

### Связь с уровнями CEFR

Рекомендуется отдельная связь многие-ко-многим: `GrammarTopic ↔ CEFRLevel`.
Это позволяет одной грамматической теме соответствовать нескольким уровням владения языком,
не дублируя её в дереве.

### Возможное дальнейшее развитие

- Добавление локализаций названий и описаний.
- Привязка теоретических материалов и примеров.
- Привязка упражнений и тестов.
- Версионирование каталога и сохранение стабильных идентификаторов тем.
- Отдельные учебные траектории для разных курсов и преподавателей.

**Примечание:** это базовая продуктовая структура ETA версии 1.0, а не исчерпывающий
академический справочник. Список тем можно расширять без изменения принципа организации дерева.
